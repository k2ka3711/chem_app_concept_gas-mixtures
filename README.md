# chem_app_concept_gas-mixtures
高等学校化学「混合気体とドルトンの分圧の法則」学習アプリ

先行アプリ `chem_app_concept_gas-laws`（気体の法則）に続く発展単元として、初学者が最もつまずきやすい「混合気体・分圧の概念・連結容器の混合・温度差平衡」を、公式の丸暗記ではなく直感的な分子運動と物理シミュレーションから理解できるWebアプリケーションです。

---

## 🌟 主な特徴と学習フロー

1. **完全単一ファイル構成（ゼロ依存）**
   - 外部ライブラリ（React, Vue, jQuery等）を一切使用せず、ネイティブ HTML5 Canvas + Vanilla JS / CSS だけで完結。
   - オフラインでもブラウザで開くだけで即座に高速動作します。

2. **5つの直感ステップ構成**
   - **ステップ1【「分圧」ってなに？】**:
     - ひとつの容器に同居する気体A（青）と気体B（赤橙）の熱運動を観察。
     - 「気体Aのみ」「気体Bのみ」の視点切り替えにより、理想気体では相手の気体に邪魔されず「自分だけで容器全体を満たしているかのように壁に衝突している（＝分圧）」という本質を体感。
   - **ステップ2【3つの発見実験】**:
     - **実験① ドルトンの法則**: 粒子数スライダーと連動し、分圧 $p_A$ と $p_B$ が積み上がって全圧 $P$ になるスタック圧力メーター。
     - **実験② モル分率**: 混合比率を変えると、分子数の比（モル比 $n_A : n_B$）と分圧の比（$p_A : p_B$）が完全に一致する様子を可視化。
     - **実験③ コックを開けて混合！**: 容器1（$1.00\,\text{L}, 4.00\times 10^5\,\text{Pa}$）と容器2（$3.00\,\text{L}, 2.00\times 10^5\,\text{Pa}$）をつなぐコックを開けると、分子が全体（$4.00\,\text{L}$）に拡散。ボイルの法則で $p_A = 1.00\times 10^5\,\text{Pa}$、$p_B = 1.50\times 10^5\,\text{Pa}$、全圧 $P = 2.50\times 10^5\,\text{Pa}$ ときれいに割り切れる数値で学習。
   - **ステップ3【公式を整理！】**:
     - 「成分気体ごとに解くか（$p_A V = n_A R T$）」「全体をまとめて解くか（$P V = n_{\text{全}} R T$）」の2大アプローチを整理。
     - 空気の平均分子量（$28.8$）の導出コラム。
   - **ステップ4【ひらめきクイズ】**:
     - 初学者が陥りがちな落とし穴（モル分率計算、分子量と分圧の無関係性、コック混合の全圧）を問う即時判定クイズ3題。
   - **ステップ5【発展：温度変化とコック開閉シミュレーター】**:
     - 模試・入試の超頻出難問である「2容器の温度差問題」をシミュレート。
     - コックが閉じているとき（シャルルの法則・左右で圧力差）と、コックが開いているとき（連通状態・$P_1 = P_2 = P$ 平衡）の振る舞いを比較。
     - 「なぜ冷たい容器に分子が多く密集するのか（$n \propto 1/T$）」を Canvas 上のリアルタイムな分子の流れと密度差で実感可能。

## 📐 科学的計算モデル

### 1. ドルトンの分圧の法則
$$P = p_A + p_B + \dots = \sum p_i$$

### 2. モル分率と分圧
$$x_A = \frac{n_A}{n_{\text{全}}} \implies p_A = P \cdot x_A$$

### 3. コック混合（温度一定・ボイルの法則）
$$p_A = P_{A0} \cdot \frac{V_1}{V_1 + V_2}, \quad p_B = P_{B0} \cdot \frac{V_2}{V_1 + V_2}$$
$$P = p_A + p_B$$
- 設定値：
  - $V_1 = 1.00\,\text{L}, P_{A0} = 4.00\times 10^5\,\text{Pa} \implies p_A = 4.00\times 10^5 \times \frac{1.00}{4.00} = 1.00\times 10^5\,\text{Pa}$
  - $V_2 = 3.00\,\text{L}, P_{B0} = 2.00\times 10^5\,\text{Pa} \implies p_B = 2.00\times 10^5 \times \frac{3.00}{4.00} = 1.50\times 10^5\,\text{Pa}$
  - $P = (1.00 + 1.50)\times 10^5 = 2.50\times 10^5\,\text{Pa}$

### 4. 2容器の温度差平衡（ステップ5）
コック開放時、両容器の圧力は等しく平衡します（$P_1 = P_2 = P$）。全物質量保存より：
$$n_{\text{全}} = n_1 + n_2 = \frac{P V_1}{R T_1} + \frac{P V_2}{R T_2} = \frac{P}{R} \left( \frac{V_1}{T_1} + \frac{V_2}{T_2} \right)$$
$$P = \frac{n_{\text{全}} R}{\frac{V_1}{T_1} + \frac{V_2}{T_2}}$$
各容器内の物質量配分（分子数比）：
$$\frac{n_1}{n_{\text{全}}} = \frac{\frac{V_1}{T_1}}{\frac{V_1}{T_1} + \frac{V_2}{T_2}}$$
